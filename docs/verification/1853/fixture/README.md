These are the actual local held-page driver and bounded mesh/remodel scripts, retained for auditing the manual app commands. `held.cjs` records the original machine checkout/output paths and starts one page under tools/browsertest.sh; adjust those paths to reproduce in another checkout. Its peer URL was a local `artifacts/football-peer.html`, whose exact body is preserved here as peer.html. It imports only production modules and builds no second world. No credentials are present. This is not presented as an unrun final-layout end-to-end automation suite.

The actual accepted native outcomes and final geometry measurements are saved in ../app/*.json; failed fixture handshakes/initial rejected-layout mesh diagnostics are retained separately. `final-layout-code.js` is a fixture-only same-world reconstruction after source-path clearance rejected the first layout; its memoized collision-list refresh is not product runtime code. `contact-code.js` calls the actual opaque mesh's triangle ray method directly because the remainder terrain intentionally disables interactive raycasts.
