# Indoor lamp glare and shade falloff (#2203)

Base: `6965828e`. The source change is scoped to indoor lamp appearance; the existing street halo path, lamp-wash distribution, point-light budget and disco implementation remain in place. Values in `LIGHTING.halo` are visual guesses, not measured bulb photometry.

`IndoorHalos` uses the existing depth-tested additive/fog-faded halo shader in one instanced quad batch at the existing lamp anchors. The source colours follow each lamp's switch/fade/supply and colour. Only changed positions/colours upload. The halo fades out by daylight 0.5, compensates renderer exposure, and is hidden at graphics quality 0. `lowMemory` allocates no halo geometry/material/batch. No extra light, shadow caster or rendering pass.

`shadeEmission` leaves each material's hue, cloth colour map and existing fold map intact. Untextured shades share 64 RGBA texels of linear radial bulb falloff (1×64, linear filtering). For an existing emissive texture, the same smooth factor multiplies its existing emissive term. The brightest part stays at the bulb's centre and the top/bottom rims dim smoothly; cylinder UVs wrap continuously at the seam. Switching off still uses the existing lamp material logic.
