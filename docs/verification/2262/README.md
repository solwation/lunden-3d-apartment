# Shared TV viewing after inactivity

Two Chromium clients using a local Worker exercised a channel change and a shared switch-off. Before each event, the receiving client's last movement was aged past 120 seconds. The client kept the same WebSocket and received the update. The room, channel and film cases also passed the 11 focused Node and Worker tests.
