# #1754: grilla eller steka fångad fisk, dolt uppdrag

Bilderna kommer från `tools/fishcooktest.cjs` (riktiga spelet, solo, kortade väntetider för napp via `FISHING.wait`). Alla kontroller i testet var gröna i samma körning.

1. `1-fisk-pa-grillen-ra.png`: den fångade braxen ligger rå på gårdsgrillens galler, grillen är otänd och locket står öppet.
2. `2-fisk-pa-grillen-klar.png`: samma fisk, gyllenbrun efter 16 s på tänd grill ("en grillad braxen"). Lågorna är tillfälligt släckta för bilden så att fisken syns.
3. `3-fisk-i-stekpannan.png`: en abborre steks i stekpannan på den tända hällen.
4. `4-beloning.png`: fisken tagen ur pannan, klar och inte bränd: märket "Hemligt uppdrag klart: Fiskelycka! +150" och poängen.
5. `5-uppgiftslistan.png`: uppgiftslistan efteråt. Det hemliga uppdraget står överst med sina steg. Innan det är klart syns det inte alls, vilket testet kontrollerar.
6. `6-medalj.png`: medaljen Fiskelycka på nivå 1 efter fem fångade fiskar.
