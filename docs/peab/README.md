# Peab-underlag för Kv. Lunden

Offentligt försäljningsmaterial (Peab/FOJAB), inte bygghandlingar. Mått som läses av här är ritningsmått.

| Var | Vad |
|---|---|
| `situationsplan.png`, `oversikt-vaning-*.png`, `l1002-l1008.png`, `l12xx-*.png`, `*-render.jpg` | Sidor ur plan- och informationsbroschyren (tidigare inlagda) |
| `kalibrerad/` | Situationsplanen och våningsöversikterna −1…4 i 300 dpi, med skalstockarna avlästa (`skalstockar.json`, m per PDF-enhet). På PNG:erna: modellens x = (px − 1909,5) × 0,042356, z = (py − 1073) × 0,042356 (#253). `modell-mot-plan.jpg` = modellen före #252/#253 ovanpå situationsplanen |
| `bostader/` | Bofakta-blad för Hus L:s andra bostäder (ritning 1:100 på A4 + skalstock): L1001 och L1008 (gavelenheterna), L1101 (över portiken), L1201–L1209 (övre etagebostäderna; L1208 ligger ovanför oss). Vår egen ritning är `L1007_mattsatt_planritning.pdf` i repots rot |
| `text/` | Textutdrag ur "Frågor och svar" och informationsbroschyren (sökbara, kan ha enstaka felkodade tecken) |

Ej inlagt (stort eller ej använt): plan- och inredningsbroschyrerna som PDF och Å-husens lägenhetsblad.
Källa: https://peabbostad.se/projekt/skane/kv.-lunden/ (blockerad från molnsessionerna).
