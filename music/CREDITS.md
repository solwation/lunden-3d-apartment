# Music credits

Music files played by the SYMFONISK speakers and the car radio (#416, `src/sonos.js`). A file is listed in a
channel's `tracks` in `SONOS.channels` (`src/config.js`) and is fetched only when that channel plays; if it fails to
load, the channel's generated music plays instead.

Rules (#416):

- Only licences that clearly allow free use on a public website: CC0 / public domain preferred; CC BY with
  attribution (then the track is also credited in the game). No NC / ND / "personal use" licences, no ripped or
  commercial music, no AI-generated tracks of unclear licence.
- Every file is listed below with its source page, its licence as read on that page and the date it was fetched.
- `.ogg` (Opus) + `.mp3` fallback for Safari, ~64–96 kbps; the whole folder ≤ 15–20 MB.
