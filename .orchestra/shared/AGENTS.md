# Agent entry point

For work in this repository, read and follow [AI.md](AI.md), the repository's host
policy for the orchestra, GitHub issue labels, verification and delivery to `main`.

When the maintainer writes `/orkester` or `$orkester`, run the orchestra for the
requested scope through [.claude/commands/orkester.md](.claude/commands/orkester.md);
clients without Claude commands follow the same files directly.
